# Chrome 旧样式缓存导致目录布局丢失

用户反馈：在 Chrome 打开公开网站，页面显示不正常。

## 已复现的原因

在用户已打开的 Chrome 网站标签页中直接读取并截图确认：

- 页面已显示 3 国、6 校、12 专业的新内容，筛选脚本正在运行。
- 自定义 `handbook.css` 只有 39 条顶层规则，包含预算样式，但没有 `.country-grid` 等目录样式。
- `.country-grid` 与 `.program-grid` 的计算样式均为 `display: block`，导致国家入口连成一行、专业卡片失去布局。
- 同时直接请求线上 CSS，得到包含目录样式的新文件，内容与本地一致。GitHub Pages 为这些资源返回 `Cache-Control: max-age=600`。

这是新 HTML 配上缓存的旧 CSS。前一轮的干净浏览器验证没有覆盖用户已有缓存的情况。

## 修复

新增 MkDocs 构建 hook，为自定义 CSS、3 个 JavaScript 和目录 JSON 生成 SHA-256 内容版本文件名。所有页面的 `href`、`src`、`data-catalog-url` 在构建时重写为对应版本。原始内容保持不变，模块脚本的 `type="module"` 保留。

新增回归检查：根页面和深层页面引用正确；内容变更会更换资源地址；无关外部链接不被改写；目录数据能独立于未变更的 JavaScript 更新。站点检查验证版本文件字节、哈希，以及页面不再引用固定资产地址。

后续公开站点检查以用户原 Chrome 标签页刷新后的计算样式、截图和实际筛选结果为准。
