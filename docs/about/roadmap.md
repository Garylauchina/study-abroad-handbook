# 推进路线与更新

本手册先把一条本科申请路径写完整，再扩展到更多目的地和学历层次。每批内容都应让读者完成具体行动，并能找到相应依据。

## 首批样章

- 中国大陆普高学生的本科申请入口和个人条件模板。
- 英国本科申请样章，包含两所大学的具体项目查证实例。
- 全程预算计算器、填写指南、付款日历和项目比较模板。
- 两个虚构家庭演练：预算能够覆盖时继续查什么，出现缺口时怎样调整。
- GitHub Pages 网站、全文搜索、手机阅读，以及集中来源记录。

这批内容用于检验手册方法。英国样章中的未公布费用、资格范围和其他待确认事项保留明确标注；它们不能作为已经解决的条件使用。

## 接下来的顺序

1. 完善英国样章的证据缺口和完整申请日程，增加录取比较与入学前后清单。
2. 按统一模板扩展德国、日本的本科路径，形成首个跨目的地比较版本。
3. 根据资料可得性和维护能力补充美国、加拿大、澳大利亚、新加坡、马来西亚和港澳。
4. 增加国际课程、预科、转学等分支；硕士与博士分别编写。

## 怎样维护

每次增加或修订具体规则，都记录官方来源、适用对象、入学年度和未解决事项。首页集中展示核验范围；招生截止日期与政策生效日期保留在相应正文中。

招生周期变化、官方通知更新或收到有依据的纠错时，优先复查受影响条目。本项目尚未启用自动定期政策核验；网站更新流程只负责检查文件并发布页面。
