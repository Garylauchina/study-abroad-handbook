# 从这里开始：大陆普高学生的本科留学路线

这部分适合主要在中国大陆读普通高中的学生，以及已经毕业、正在准备本科申请的读者。先完成一张个人条件表、一张全程预算表和一张项目比较表，再决定向哪些项目投入考试、材料和申请费用。

手册提供判断方法。具体学校是否接受你的学历、成绩和申请身份，要查对应项目及入学年度的官方要求。硕士、博士、国际课程和转学路径暂未在本入口展开。

## 第一步：和家人写下三个边界

把“为什么留学”写成能够比较的目标，例如希望学习的专业内容、能接受的教学语言，以及愿意在哪类环境生活。再写下家庭为整个学位提供的人民币资金上限、最晚入学时间和能够接受的额外准备年限。家庭日常开支和应急储备应先留出。

同时保留一个可执行的备选方案，例如国内升学、在已有条件下寻找其他项目，或者先补齐能力再申请下一入学年度。备选方案也要有时间线和费用，不能只有“到时再说”。

## 第二步：盘点自己实际持有的条件

在个人条件表中填写：

- **申请身份**：国籍、所持证件、居住地、申请时年龄；只记录与资格核验有关的信息。
- **学习经历**：普通高中、在读年级或毕业时间、是否有间隔年或其他高等教育经历。
- **学术准备**：高中课程与成绩、是否参加高考、已经获得和预计获得的成绩，以及目标专业所需的科目背景。
- **语言与时间**：已有语言成绩、考试日期、能够用于准备的时间；没有成绩就填写“未取得”。
- **家庭边界**：全程预算上限、每年可提供金额、需要保留的应急资金和支持条件。

将每个字段分成“已有证明”“预计获得”“尚未满足”。预计成绩不能写成已取得成绩；留空也不能被理解为符合要求。个人表建议在自己的设备上保存，公开讨论时去除证件号码、姓名、联系方式和材料原件。

## 第三步：先核实路径，再研究学校

直申本科、预科或其他衔接课程可以作为待比较的路径。每条路径都要回答：凭什么资格入学、进入下一阶段还要满足什么条件、总共读多久、由谁授予最终学位，以及整个过程在哪里完成。

看到“可衔接本科”时，继续查清具体可升入的项目、成绩及语言要求、是否另行选拔、未升入时的退出安排。不要把被准备课程录取理解为已经被最终本科录取。

先按硬条件建立一个小规模候选表：学历资格、专业先修、语言、总资金和时间。关键条件尚未查清的项目可以保留为候选，但标为“待核实”，暂不进入付款决定。

## 第四步：用统一口径留下可比较的项目

每个候选项目分别填写预算和比较表。预算要覆盖整个学位，包括额外准备阶段；比较表要落实到项目、校区、学位授予方和入学年度。排名可以是辅助信息，不能替代课程内容、毕业要求、费用和申请资格。

把下一步写成一项具体行动：“在某日前，从项目官网确认是否接受我的高中资格并保存来源”，比“了解英国留学”更容易完成。查不到答案时，将问题写给有权解释该规则的学校部门，并保存书面答复及其适用范围。

## 完成本页后的交付物

你应当能向家人说明：希望获得什么、现有条件缺什么、全程可投入多少、正在比较哪些具体项目，以及哪一个未解决问题会改变决定。

建议阅读顺序是：个人条件盘点 → 全程预算 → 项目比较 → 目的地样章 → 申请日程。只有当资格和资金两方面都能解释清楚时，才继续安排需要付费的申请步骤。
