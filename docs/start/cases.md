# 两个虚构家庭：怎样使用预算和项目比较表

以下学生、项目、币种和金额全部虚构，只用于检验工具与决策方法。U 是假设的当地货币；这些数字不是英国或任何国家的现行费用、汇率、资格或录取信息。

## 两个家庭使用同一组演练输入

| 预算输入 | 虚构数值 |
| --- | ---: |
| 学制 | 3 年 |
| 年学费 | 20,000 U |
| 每月生活费／每年生活月数 | 1,000 U／12 个月 |
| 每年其他费用 | 1,000 U |
| 一次性费用 | 3,000 U |
| 全程已落实资助 | 10,000 U |
| 可退押金 | 1,500 U |
| 汇率／预备金比例 | 9 元人民币／U；10% |

资助前支出为 102,000 U，预备金为 10,200 U；扣除已落实资助后，总净成本为 102,200 U，即 **919,800 元**。加上可退押金，全程总资金参考为 103,700 U，即 **933,300 元**。

这里的 10,000 U 资助是在虚构案例中设定为已经落实的金额。读者自己的资助尚未明确时，应填 0。全程总资金参考也不是月度现金峰值，两个家庭都还要填写付款日历。

## 案例一：基本预算能够覆盖，继续筛选项目

小林正在读普高，对某类理工课程感兴趣。家庭在保留日常开支和应急资金后，可用于整个本科阶段的资金上限为 **100 万元人民币**。上述演练项目需要准备 933,300 元，预算余量为 **66,700 元**。

将汇率调为 9.45 元人民币／U，即增加 5%，其他条件不变，资金参考变为 **979,965 元**，仍在家庭上限内，余量降至 20,035 元。这个压力情景帮助家庭观察余量如何缩小，不表示已经覆盖所有风险。

家庭可以继续筛选：核验项目是否接受小林持有的高中资格，查清专业先修要求，比较另一个课程方向相近的项目，并按学费付款与资助到账时间编排现金日历。预算够用没有消除资格缺口；资格确认前不据此支付不可退费用。

如果后续发现需要额外准备课程、资助较晚到账或费用上调，应重新计算，而不是继续沿用这次预算结论。

## 案例二：存在资金缺口，先改变方案

小周家庭可提供的留学资金上限为 **70 万元人民币**。使用同一组演练输入，资金参考仍为 933,300 元，超过家庭上限 **233,300 元**。这个方案当前没有通过预算检查。

“到了当地做兼职”或“以后可能有更多奖学金”不能消除当前缺口。家庭可以按顺序完成三件事：

1. 寻找总成本更低的候选项目，并从资格、课程和学位授予安排重新核验，不能只替换预算里的学费。
2. 核实是否存在适用的额外资助；获得明确结果后，再把已落实部分计入预算，确认到账时间与覆盖用途。
3. 同时保留国内升学或下一申请年度的具体方案，给考试、申请费用和最晚决定日期设上限。

为检验第一条，另设虚构候选 C：学制仍为 3 年，年学费 10,000 U，生活费每月 700 U，年度其他费 1,000 U，一次费 3,000 U，押金 1,500 U，每年生活 12 个月。汇率和预备金比例不变。原项目资助不能直接转移，因此 C 的已落实资助填 **0**。

C 的资助前支出为 61,200 U，预备金 6,120 U，总净成本 67,320 U。加上押金后的资金参考为 **619,380 元**，比家庭上限低 80,620 元。它只是值得进一步查证的候选，尚未证明资格、学习内容和生活条件合适。

如果 C 的实际费用或资格核验没有通过，就继续执行备选方案。演练的成果是一套能够控制损失并继续推进的决定，不是必须在当年完成留学。
