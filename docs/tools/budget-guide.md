# 全程预算：先算完成学位需要准备多少资金

预算工具用于比较方案，不代表学校账单或签证资金要求。先保存每笔费用的原币、计价周期和来源，再换算人民币。一个计算场景使用一种当地币；跨币种支出要先按注明的汇率换算，保留原始金额，避免漏算或重复。

## 如何填写输入

| 输入字段 | 填写口径 |
| --- | --- |
| 年学费 | 当地币／学年；使用对应项目及入学年度金额 |
| 每月生活费 | 当地币／月，按住房、饮食、交通等自行分项后合计 |
| 学制 | 本次计算所覆盖的年数；衔接阶段费用不同，应另算后合并 |
| 每年生活月数 | 默认 12 个月；只有有依据时才调低 |
| 每年其他费用 | 当地币／学年，如必须支付的年度费用；已计入生活费的项目不再填写 |
| 一次性费用 | 当地币／全程，包含自行分项的考试、材料、签证、机票等费用 |
| 已落实资助 | 当地币／全程；只计入已有明确依据、可用于本次支出的金额 |
| 可退押金 | 当地币，单列现金占用；不加入最终净成本 |
| 汇率 | 1 单位当地币对应多少人民币，另记取值日期 |
| 预备金比例 | 对资助前的学费、生活费、年度费和一次费合计计提 |

可退押金的退款条件必须另查。如果押金后来抵扣学费，它属于提前付款，应在付款日历中体现，不能再作为一项学费支出。无法确认能退回的金额应先列为待核实，并另做不能退回的情景。

未来年份的学费上涨、延长学制和大额旅行可能超出简单模型。先记录这些假设；如不同年份差异明显，应使用逐年明细，不要只用首年金额乘学制。

## 计算方法

```text
学费 = 年学费 × 学制
生活费 = 每月生活费 × 每年生活月数 × 学制
年度费用 = 每年其他费用 × 学制
支出 = 学费 + 生活费 + 年度费用 + 一次性费用
预备金 = 支出 × 预备金比例 / 100
总净成本 = max(0, 支出 + 预备金 - 已落实资助)
准备资金 = 总净成本 + 可退押金
人民币金额 = 对应当地币金额 × 汇率
```

**准备资金是全程总资金参考，不是严格计算出的月度现金峰值。** 资助到账晚于学费付款时，仍需过桥资金；多笔押金的支付与退回时间不同，真实现金占用也不同。因此预算通过后，还必须建立付款日历。

## 再做一张付款日历

每笔记录包括：费用名称、原币金额、人民币参考额、到期日期、最早可付日期、付款对象、已付金额、退款条件和日期、预计资助到账日，以及凭据位置。按月份汇总家庭需要支出的现金，同时检查当时实际可用的资金。

预备金应单独保留，不能因为总额“看起来够”就提前分配给可选消费。不同项目的预备金比例、学制和生活月数应保持一致，或者解释差异，否则低价可能只是少算了项目。

## 把缺口和不确定性算出来

家庭可用于留学的资金减去准备资金，得到本场景的余量或缺口。基础预算不扣除尚未获得的奖学金、不确定的兼职收入和毕业后收入。资助有续领条件时，已经落实部分与后续条件部分要分开。

至少再比较两种变化：汇率更不利，以及费用或学习时间增加。变化幅度由家庭自行设置，明确为压力情景，不写成对未来的预测。若缺口只能靠未落实收入填平，当前方案尚未通过预算检查。

工具的空白输入不代表任何真实国家的价格。页面中的演练数字均为虚构；实际付款前，应逐项替换为有来源的金额，并重新核对资助到账和退款安排。
