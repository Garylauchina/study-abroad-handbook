# 项目比较：一行只比较一个具体本科项目

同一大学的不同项目、校区或入学年度可能对应不同条件。比较表的一行应写完整的“大学＋项目＋学位层次＋校区＋入学年度”，避免把校名当成已经确认的申请方案。

表格可以帮助缩小范围。它不能替代项目官网、正式录取条件或签署的付款文件。

## 建议保留的字段

| 字段组 | 需要记录的内容 |
| --- | --- |
| 项目身份 | 官方校名、项目正式名称、学位层次、项目网址、入学年度与开学批次 |
| 学习与授予 | 校区、实际授课地点、授课语言、学制、学习方式、学位授予方；合作或联合项目另记各阶段安排 |
| 大陆申请资格 | 适用的国籍及申请者类别、普通高中学历要求、是否及如何使用高考成绩、在读或已毕业限制 |
| 入学条件 | 必修或先修科目、学术要求、语言要求、其他考试、面试或作品材料；区分申请时与入学前应满足的条件 |
| 学习内容 | 必修课、可选方向、实习安排、考核与毕业要求，以及学生本人看重的学习内容 |
| 申请安排 | 官方入口、申请费、材料、申请和补件截止日期、时区；奖学金与接受录取的期限分列 |
| 全程费用 | 原币、计价周期、费用适用年度、是否覆盖整个学制、预算表链接、人民币换算假设 |
| 付款与退出 | 接受录取所需付款、抵扣或退款方式、住宿安排、未满足条件及延期入学时的处理规则 |
| 资助 | 已落实金额、待申请金额、覆盖用途、期限、到账安排及续领条件 |
| 证据与缺口 | 官方来源、支持结论的具体位置、核验日期、适用范围、证据状态、尚待回答的问题和下一步 |

本科职业目标涉及专业准入时，在“证据与缺口”中单列核验事项。学位授予机构、学历认可和职业准入分别记录，不用一个“认可”勾选框概括所有问题。

## 先排除不满足条件的方案

用三个判断栏代替一个模糊的总分：

- **资格**：已核实符合／有条件可补齐／明确不符合／待核实。
- **资金**：全程和付款日历均能覆盖／存在缺口／待核实。
- **个人适合程度**：学生能说明吸引自己的课程和环境，并列出仍有顾虑的地方。

“已核实符合”仅表示表内核对的公开条件与个人情况相符，不代表录取承诺。只要关键资格、费用或授予安排未确认，就保留缺口，不用平均分掩盖它。

完成硬条件筛选后，再按家庭重视的因素比较：课程内容、全程成本、学习与生活支持、地域偏好等。权重由学生和家人讨论；不要把精确到小数点的分数写成客观质量结论。

## 一条来源怎样才够用

“官网说可以”不够具体。建议记录：“某项目页面的某段说明，适用于某入学年度和申请者类别，于某日核验”。若页面只介绍一般国际学生条件，尚不能确认大陆普通高中资格，就把后者继续列为待核实。

官方来源之间存在冲突时，同时保留链接和差异，向负责该项目招生的部门询问。书面答复也要记录日期、对象和问题原文，避免把对某一个人的答复推广给所有申请者。

比较表完成后，每个保留项目都应对应一项明确的下一步，例如补齐语言条件、确认高中资格或重算住宿费用。需要支付申请费或押金前，再复查那些会改变决定的关键事实。
