# 海外大学留学手册

面向中国大陆学生及家长。从自己的条件和家庭预算出发，逐步完成大学与专业选择、申请准备和入学安排。

[开始准备本科申请](start/undergraduate.md){ .md-button .md-button--primary }
[计算全程预算](tools/budget.md){ .md-button }

## 先做这四件事

<div class="reading-route" markdown>

### 01　盘点条件，明确目标

把课程体系、成绩、语言、入学年度和家庭底线放在一张纸上，找出需要补齐的条件。

[填写自己的条件清单 →](start/undergraduate.md)

### 02　算整个学位需要多少钱

学费、生活费、一次性支出、已落实资助和可退押金分别计算，再看付款节点能否承受。

[打开预算计算器 →](tools/budget.md)

### 03　比较具体大学项目

对照大陆学历资格、专业课程、学制和费用，记录每个判断的官方依据。

[使用项目比较模板 →](tools/compare.md)

### 04　沿一条路径走一遍

从英国本科样章了解怎样查资格、整理申请日程、处理录取条件，并继续查找入学安排。

[阅读英国样章 →](destinations/uk.md)

</div>
